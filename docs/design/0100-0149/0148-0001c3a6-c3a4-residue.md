## Item \(i\) slice 1 — cross\-type integer array literals as index quals

PG reference: match\_saopclause\_to\_indexcol \(indxpath.c\) — the
operator only has to be in the index column's opfamily. integer\_ops holds
the cross\-type `=` \(int24eq, int48eq, int84eq, …\).
\_bt\_preprocess\_array\_keys compares with the cross\-type ORDER proc, and
\_bt\_merge\_arrays intersects arrays on one column.

### The gap

- `unique1 = ANY ('{33,44}'::bigint[])` on an int4 column was refused:
  castIsColumnArrayType requires the literal's element type to equal the
  column's.
- The qual stayed a Filter, printed without its cast \(`'{33, 44}'`\),
  where PG merges it into the Index Cond.

### The fix

- **crossIntArrayLiteral:** accepts a cast array literal of another
  integer type \(int2 / int4 / int8\) as a column qual on an integer
  column \(saopColumnQuals\).
  - The probe keeps only the elements inside the column type's range. One
    outside can match no key; PG's exact cross\-type comparison finds it
    unequal to every value.
  - If none is inside, the array is empty and matches nothing.
- **SAOPColQual.ArrayText:** keeps the literal as PG prints the Const
  \(`'{33,4400000000}'::bigint[]`\); EXPLAIN renders it verbatim.

### Verification

- **Scratch PG:** plans and rows match for in\-range, mixed and
  all\-out\-of\-range elements, and for `int2col = ANY ('{2,3}'::int4[])`.
- **TestCrossTypeIntegerArrayColumnQual:** pins 2 plans and 3 row
  results; the plans fail with the arm disabled.
- **Regress:** create\_index 2708→2689.
- **Gates:**
  - units, tpch\-spotcheck, sf025 same=99;
  - fire\-set fires=none on sf025, sf1 and TPC\-H;
  - acceptance 24 MATCH.

### Not covered

- **Primary probe:** a cross\-type literal as the primary probe array
  \(nothing else on the column\) is still refused there. Only the
  column\-qual merge takes it.
- **Untyped literal on int2:** an untyped `'{1,2}'` on a smallint column
  prints `'{1,2}'::integer[]` where PG prints `smallint[]`.
  inListArrayConst cannot tell an `IN (1, 2)` list \(integer\) from an
  untyped array literal \(the column's type\).
- **Mixed\-type OR on a bitmap arm:** `tenthous = 1::int2 OR tenthous =
  3::int8 OR …` stays a Filter. PG makes a BitmapOr of an int2 equality
  arm and an `= ANY ('{3,42}'::bigint[])` arm.
