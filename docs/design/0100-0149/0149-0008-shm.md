# 0149-0008 — recovery/t/017\_shm.pl: parked on architecture

Status: parked `[!]` blocked\-on owner: architecture \(2026\-11\-23\).

Upstream: `postgres/src/test/recovery/t/017_shm.pl`; `src/backend/port/sysv_shmem.c`
\(`PGSharedMemoryCreate`, `PGSharedMemoryAttach`, `PGSharedMemoryIsInUse`\), `src/backend/utils/init/miscinit.c`
\(`CreateLockFile`, the postmaster.pid shmem\\-key line\).

## What the test asserts

The `.pl` has three assertions; everything before them only exercises start, restart and kill9 while a
conflicting SysV segment keyed by the data directory's inode exists, and asserts nothing.

1. `slow query started` — a session runs `SELECT wait_pid(pg_backend_pid())`, a C function from the regress
   module's shared library, and the test polls `pg_stat_activity` for it.
2. `detected live backend via shared memory` — after `kill9` of the **postmaster** \(only\) and removal of
   postmaster.pid, a new start must refuse with "pre\\-existing shared memory block ... is still in use", because
   the orphaned backend is still attached to the old SysV segment \(`PGSharedMemoryIsInUse` sees `shm_nattch > 0`\).
3. `single-user mode detected live backend via shared memory` — `postgres --single` refuses the same way.

The test then `pg_ctl kill QUIT`s the orphaned backend by its OS PID and restarts.

## Why goopg cannot pass it without a process\\-model change

- goopg serves every connection inside one OS process. `kill9` of that process ends every backend with it, so the
  state the test probes — a backend that outlives its postmaster — cannot occur. Assertions 2 and 3 have nothing to
  detect.
- goopg has no SysV shared memory segment at all, hence no `shm_nattch` interlock and no shmem key line in
  postmaster.pid.
- The final step kills a backend by OS PID. goopg's `pg_backend_pid()` is a synthetic per\\-connection number
  \(`internal/executor/expr.go`\); signalling it would hit an unrelated process \(milestone rule C4\).
- Assertion 1 needs a C function loaded from a shared library \(`wait_pid` in regress.so\).

The milestone's architecture escape hatch \(docs/milestones/0149\-replication\-tap\-port.md, C4\) names `017_shm`
explicitly. Substituting a whole\\-server SIGKILL would not be a port.

## Reopen condition

Reopen when the owner decides a process model in which backends are OS processes attached to a shared memory
segment that can outlive the postmaster \(the same decision M0149\-0004 waits on\).
