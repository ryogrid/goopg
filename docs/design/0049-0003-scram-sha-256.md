# 0049-0003 — SCRAM-SHA-256 authentication

**Status:** draft
**Date:** 2026-05-04
**Milestone:** 0049 — Protocol parity
**Supersedes:** —

## Context

goopg supports `trust` and (per ref-021 + root-0003) MD5; SCRAM-SHA-256
is the upstream default since PostgreSQL 14 and is required by some
managed-cloud clients. This milestone adds the server side of the SCRAM
exchange (RFC 5802) using SHA-256 as the hash and PBKDF2 for the
client-key derivation. Channel binding is **deferred** to a follow-up.

## Plan

1. **Stored secret format.** `pg_authid` (M0030) gains a column
   `rolpassword` whose value can be either:
   - `md5xxxxxxxx...` (existing format — kept for backwards compat), or
   - `SCRAM-SHA-256$<iter>:<salt>$<storedkey>:<serverkey>` (new), where
     `iter` is the iteration count, `salt` is base64, and the two keys
     are base64.
   `pg_hba.conf` parser learns the new `auth-method = scram-sha-256`
   keyword.
2. **`AuthenticationSASL` exchange.** Server-side state machine:
   - Send `AuthenticationSASL` (codes 10) listing `SCRAM-SHA-256`.
   - Receive client first message `n,,n=<user>,r=<client-nonce>`.
   - Reply `AuthenticationSASLContinue` with `r=<client-nonce|server-
     nonce>,s=<salt>,i=<iter>`.
   - Receive client final `c=biws,r=...,p=<client-proof>`.
   - Verify: compute `clientSignature = HMAC(storedKey, authMessage)`;
     `clientKey = clientSignature XOR clientProof`; `H(clientKey)`
     should equal `storedKey`.
   - On success: send `AuthenticationSASLFinal` with `v=<server-
     signature>`, then `AuthenticationOk`.
3. **Crypto.** `crypto/hmac` + `crypto/sha256` + `golang.org/x/crypto/pbkdf2`.
4. **Password-set path.** New executor opcode for `ALTER USER ... PASSWORD '...'`
   computes salt + iterations on the fly and stores in the new format.
5. **Password-set during initdb.** `goopg init --user=ryo` accepts
   `--password=<plaintext>` and stores it in SCRAM format.

## Definition of Done

- `psql -h localhost ...` connects against `pg_hba.conf` rule
  `host all all 0.0.0.0/0 scram-sha-256`.
- pgx + JDBC drivers connect successfully against the same rule.
- Golden-file replay test of a SCRAM exchange against a fixed iter +
  salt.
- `MD5` rules continue to work (regression).
