## Most-likely diverger

Block representation → f1. `l_orderkey` is insertion-ordered
(lineitems appended per order), so a uniform-all-blocks sample is
f1-rich (singletons everywhere → Duj1 est 1.17M) while PG's
few-blocks sample sees clustered ranges (fewer singletons → Duj1
est 347k). Same formula, sampler-driven inputs. The true distinct
(≈1.5M) sides with goopg — PG's undercount is the load-bearing
"error" behind Q4's 0.23.
