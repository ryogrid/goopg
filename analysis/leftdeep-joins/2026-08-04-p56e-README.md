  this is the LEGACY planner — P5.6's sizer is still inert and this is the
  before-picture P5.9 re-measures against.
- TPC-H bench cluster on 65433, SF=1, started by `bench/tpch/setup_goopg.sh`
  with `GOGC=100 GOMEMLIMIT=12GiB`.
- `--serial` (`max_parallel_workers_per_gather = 0`) and `--warm-stats`
  (explicit `ANALYZE <table>` per table on the audit session): see §5.1 for
  why both are load-bearing.
- `--timeout 150s`; nothing timed out. Whole run 12 min 42 s.

Reproduce:

```sh
go build -o /tmp/estimate-audit ./cmd/estimate-audit
GOGC=100 GOMEMLIMIT=12GiB bench/tpch/setup_goopg.sh
/tmp/estimate-audit --label <YYYY-MM-DD>-<slug> --timeout 150s
bench/tpch/stop_goopg.sh
```

Row-count caveat inherited from the cluster: the anchors are load-dependent
(`bench/tpch/spotcheck_expected.env`), so an audit captured after a TPC-H
reload is not comparable row-for-row with this one — re-capture the baseline
in the same loop as any reload.
