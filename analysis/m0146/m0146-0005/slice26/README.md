# M0146-0005 slice 26 — Q19 `{ss, dd, item}` seed-order divergence: priced-input routing recon

Post-M0146-0027-slice-3, Q19's SF0.25 first-divergence record moved off the
aggregate shape (now matched) to a depth-10 join-order record:

- PG seeds the parallel chain `store_sales ⋈ date_dim` (partial hash,
  91 rows/worker), then NL-probes `item` — and onwards through customer /
  customer_address / store.
- goopg seeds `store_sales ⋈ item` (3780 rows/worker), then
  `Memoize -> Index Scan` on `date_dim`, and onwards identically.

## Verdict

Not an enumeration, reach, or comparator defect. Both seeds and both
`{ss,dd,item}` NL orientations are generated by both engines; goopg's
`addToPartialPathlist` (`internal/optimizer/path.go`) already implements
PG's `add_partial_path` adjudication (disabled-count, fuzzy total-cost,
pathkey superiority, tight `1.0000000001` fuzz, incumbent-retention on
COSTS_EQUAL — confirmed by direct code comparison this session). The flip
is driven entirely by the *priced inputs*: physical `relpages` and the
parameterized index-probe base cost.
