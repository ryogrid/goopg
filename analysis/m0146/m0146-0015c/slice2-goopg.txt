Data:
  create table ta (k int, y int, tag text);
  create table tb (k int, w int);
  create table tc (x int, z int);
  insert into ta values (1,10,'a1'),(2,20,'a2'),(3,30,'a3'),(4,40,'a4');
  insert into tb values (1,100),(1,101),(2,200),(3,999);
  insert into tc values (10,100),(20,200),(30,300);

Hand-computed expectation for the canonical shape: a1 (b.w=100 ->
tc(10,100) hit) and a2 (tc(20,200) hit); a3 fails (c.z=999 no match);
a4 has no b row.

1. Canonical nested EXISTS — now a semi join with the inner EXISTS
   kept as a pre-lowered SubPlan in the Join Filter (PG's shape):

   select tag from ta a where exists (select 1 from tb b
     where b.k = a.k and exists (select 1 from tc c
       where c.x = a.y and c.z = b.w)) order by tag;
   -> a1, a2   (correct)

   Hash Semi Join
     Hash Cond: (a.k = b.k)
     Join Filter: (EXISTS(SubPlan 1))
     SubPlan 1
       ->  Seq Scan on tc c
             Filter: ((x = a.y) AND (z = b.w))
     ->  Seq Scan on ta a
     ->  Seq Scan on tb b

   PG 18.3 (pg-oracle.txt) prints the same semi join; its Join Filter
   is the hashed-ANY form (`ANY ((a.y = (hashed SubPlan 2).col1) AND
   (b.w = (hashed SubPlan 2).col2))`) — slice 3
   (convert_EXISTS_to_ANY) remains for that rendering.

2. NOT EXISTS — the Anti analogue:

   select tag from ta a where not exists (<same body>) order by tag;
   -> a3, a4   (correct complement)

   Hash Anti Join
     Hash Cond: (a.k = b.k)
     Join Filter: (EXISTS(SubPlan 1))
     ...

3. Correlated kept ANY — `b.w IN (select c.z from tc c where
   c.x = a.y)` rides the same way (its own pull-up declines; the kept
   subplan is re-based identically):

   -> a1, a2   (correct)

Execution notes: the kept SubPlan's correlation arrives as
pre-lowered PARAM_EXEC args — negative sentinels installed at pull-up
re-base, renumbered into the flat ParamExec space by
lowerSubPlanParams; Args are problem-space ColumnRefs re-based by
